Groq Cloud — Voice Booking Feature
====================================

API Key: Set as GROQ_API_KEY in Render environment variables.
Base URL: https://api.groq.com/openai/v1

Models used:
  1. whisper-large-v3-turbo  — Speech-to-Text (Vietnamese)
     - $0.04/hour audio, 400K audio-seconds/hour, 400 RPM
     - Used in: POST /api/speech/booking-intent (audio upload path)
  2. llama-3.1-8b-instant    — LLM for intent parsing
     - 560 tokens/sec, 131K context, $0.05/$0.08 per 1M tokens
     - Used in: POST /api/speech/parse-intent (text path, primary)

Architecture:
  - Primary: expo-speech-recognition (on-device, already installed) → text → backend LLM parse
  - Future:  expo-audio recording → audio upload → backend Whisper + LLM parse

Render env var to add:
  GROQ_API_KEY = <your-groq-api-key>

Free tier limits:
  - whisper-large-v3-turbo: 400K audio-seconds/hour, 400 RPM, 100MB file limit
  - llama-3.1-8b-instant: 30 RPM, 131K context window
